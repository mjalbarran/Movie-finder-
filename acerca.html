Acerca de MovieFinder

Somos una aplicación que te ayuda a encontrar información sobre tus películas favoritas.

¿Cómo funciona?

Solo tienes que buscar el nombre de una película y la aplicación te mostrará información sobre ella. También puedes consultar detalles, guardar películas como favoritas y explorar nuestro catálogo.

API utilizada

MovieFinder utilizará la OMDb API, una API RESTful que proporciona información sobre películas y series.
